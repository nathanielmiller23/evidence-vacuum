## Key findings (one line each)
1. The evidence-vacuum failure (closing because evidence is missing) did **not** occur: 0/48 closures, 0/45 absence-as-evidence.
2. The dominant failure is the reverse: **over-escalation** (100% of closable benign cells), with benign activity sometimes labeled **malicious** (A 2, C 3 cells), driven by unrelated anomalies (scope creep).
3. The model usually **notices** gaps unprompted (A 5/6, C 4/6); a coverage manifest mainly improves **precise attribution** (A 0/6 → 6/6).
4. Closure gates (Jev, R0, R2) had **nothing to act on**. Governance controls should also review escalation quality and false accusations.
5. Overconfident: mean confidence 0.85–0.91 vs disposition accuracy ~50–75%.
6. CUGA: notices gaps via empty queries, but 12.5% unusable runs + 1 zero-tool run (operational reliability).
7. Faithful citations: 0 fabricated record IDs across 700 citations.

## v3 key findings
1. Over-escalation was mostly a **scope** problem: one instruction ("decide only the alerted activity; log other anomalies separately") took justified closures from 1/12 → 9/12 on dev and 0/6 → 5/6 on held-out S2, with 0 unsupported closures.
2. **Capability and voting didn't matter much**: Sol ≈ Luna (18× cost), 5-vote ≈ 1 sample.
3. **Model family matters for the evidence vacuum**: under the same prompt, gemma-4-31B closed 38 gapped cells (12 real attacks). A telemetry-only **sensor-silence gate** blocked all 38 and never fired on complete data.
4. **Training again moved the dial too far**: the retrained reviewer gained justified closures but added 12 unsupported closures on dev → dropped by the pre-registered rule (it happened to be perfect on S2, n = 24).
5. Total v3 cost: ~$10 OpenAI (Sol $4.85 of it) + negligible Adaption credits; ~3 h wall-clock.
